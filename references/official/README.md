# Official References

Place official source files here only when redistribution and repository visibility are acceptable.

For each file, create a companion `_SOURCE.md` file containing:

- official title
- issuing organization
- original URL
- retrieval date
- SHA-256
- authoritative use
- limitations
- redistribution note

The TIMS PDF was not bundled in this seed package because the official URL could not be retrieved during package creation and redistribution permission was not assessed.
