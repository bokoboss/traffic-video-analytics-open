# UI Design Principles

1. Show the current workflow step and completion state.
2. Keep the video and geometry central during setup.
3. Use domain terms familiar to traffic engineers.
4. Hide model thresholds from normal users unless Advanced is opened.
5. Explain why an event needs review.
6. Preserve undo and audit history.
7. Never silently reuse stale results.
8. Show source time and elapsed video time together when reviewing.
9. Make the difference between automatic, reviewed and certified visible.
10. Avoid decorative visual complexity that competes with evidence.
