# Keyboard Shortcuts

## Global

| Shortcut | Action |
|---|---|
| `Ctrl+K` | Command palette |
| `Ctrl+S` | Save current configuration |
| `Ctrl+Z` | Undo current reversible action |
| `Ctrl+Shift+Z` | Redo where supported |
| `Esc` | Close transient layer or cancel active drawing |
| `?` | Shortcut help |

## Playback

| Shortcut | Action |
|---|---|
| `Space` | Play/pause |
| `←` / `→` | Previous/next frame |
| `Shift+←` / `Shift+→` | ±5 seconds |
| `J` / `L` | Decrease/increase playback speed |
| `K` | Play/pause alternative |
| `[` / `]` | Previous/next event |
| `F` | Fit video |
| `+` / `-` | Zoom |

## Scene setup

| Shortcut | Action |
|---|---|
| `V` | Select |
| `H` | Pan |
| `R` | ROI |
| `X` | Exclusion |
| `C` | Count line |
| `I` | Entry zone |
| `O` | Exit zone |
| `P` | Pedestrian crossing |
| `Delete` | Delete selected geometry |
| `Arrow keys` | Nudge selected point/object |
| `Shift+Arrow` | Larger nudge |

## Review

| Shortcut | Action |
|---|---|
| `A` | Approve |
| `C` | Change class |
| `M` | Change movement |
| `E` | Exclude |
| `N` | Add manual event |
| `G` | Link tracks |
| `U` | Undo last review action |
| `Enter` | Apply active action |
| `↑` / `↓` | Previous/next queue item |
| `Shift+N` | Next unresolved |
| `Q` | Toggle unresolved-only filter |

## Rules

- Shortcuts do not fire while typing in an input unless explicitly safe.
- Destructive actions never complete from a single unmodified key.
- Every shortcut has a visible menu/action equivalent.
- Thai and English layouts must not change the shortcut meaning.
