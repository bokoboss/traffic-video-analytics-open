## Setup flow

1. Select video and confirm source
2. Confirm start date/time/timezone
3. Select analysis window
4. Select road-segment/intersection template
5. Draw ROI, lines and zones
6. Configure movement labels
7. Run a short trial
8. Start processing

## Review flow

- filter by time/class/movement/QC/confidence
- display event list and evidence
- keyboard actions: approve, change class, change movement, exclude, add, undo
- preserve clear difference between auto and reviewed values

## Results flow

- total volume
- pending review count
- class × direction table
- entry × exit matrix
- 15-minute chart
- PHF
- click any cell to filter underlying events

## Visual direction

- white/light-gray application surfaces
- charcoal or navy text
- red accent used sparingly
- video workspace may use dark background
- Thai-readable typography
- no dense executive dashboard
- status must use icon/text, not color alone
