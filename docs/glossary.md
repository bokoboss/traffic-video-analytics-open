# Glossary

| Term | Meaning |
|---|---|
| AutoCountEvent | Immutable machine-generated count event |
| EffectiveCountEvent | Result after applying ordered review actions |
| ReviewAction | Append-only human correction or approval |
| Certification | Formal confirmation of an exact result version |
| PTS | Presentation timestamp from the media timebase |
| ROI | Region of interest |
| Counting line | Directed geometry used for crossing events |
| Entry/Exit zone | Areas used to infer movement |
| Movement | User-defined entry-to-exit path such as NB-L |
| Technical duplicate | Same event inserted more than once by retry |
| Analytical duplicate | Same real object counted twice because of tracking failure |
| Stale result | Result no longer current because an input changed |
| Processing segment | Retryable/checkpointable part of a run |
| Model bundle | Detector/classifier/tracker/config/runtime provenance |
| PHF | Hourly volume divided by four times the maximum 15-minute volume |
| TIMS taxonomy | Official DOH vehicle-classification system to be verified |
